DedispersionTree¶

class pirate_frb.core.DedispersionTree¶

Output geometry of the dedisperser, for one (primary tree, early trigger) pair.

This is what a downstream consumer needs in order to interpret dedispersion outputs: the output array shapes and the frequency subbands searched. The methods which INTERPRET a tree – decoding out_argmax tokens, the subband index mappings – are DedispersionPlan methods taking an itree.

A tree is not constructible on its own: trees come from plan.trees, and the DedispersionPlan constructor is the only implementation of the geometry. Use DedispersionPlan(config, mega_ringbuf=False, gpu_kernels=False) to get at them with no GPU – which is what lets archived variance maps be analyzed anywhere.

Note plan.trees is a fresh list of COPIES on every attribute access, so code that needs one tree repeatedly should cache it.

Trees are enumerated by primary tree, then by DECREASING early-trigger level (earliest trigger first, then the main early_trigger_level=0 tree). To go from a (primary_tree_index, early_trigger_level) pair to a tree index, use DedispersionPlan.dedispersion_tree_index(); the reverse is just reading those two attributes of plan.trees[itree].

Attributes (read-only):

  • primary_tree_index (int) – the primary tree this belongs to. Also selects the associated stage1 tree, whose input is downsampled in time by 2**primary_tree_index.

  • early_trigger_level (int) – 0 for the main tree, 1 or more for early triggers (larger means earlier).

  • amb_rank (int) – ambient rank of this tree (the dd_rank of the associated stage1 tree).

  • dd_rank (int) – active dedispersion rank of this tree.

  • primary_tree_rank (int) – rank of this tree’s primary-tree family, from which its early triggers count down.

  • nt_ds (int) – downsampled time samples per chunk, i.e. config.time_samples_per_chunk divided by 2**primary_tree_index.

  • frequency_subbands (FrequencySubbands) – the subbands searched in this tree. Can be a strict subset of the config’s subbands: early triggers and downsampling restrict which ones a given tree searches.

  • primary_tree (PrimaryTree) – an exact copy of config.primary_trees[primary_tree_index] (nothing is resolved into it – the resolved factors are dm_downsampling and time_downsampling below).

  • nprofiles (int) – number of peak-finder time profiles, equal to 1 + 3*log2(primary_tree.max_width).

  • ndm_out, nt_out (int) – this tree’s out_max and out_argmax arrays have shape (beams_per_batch, ndm_out, nt_out).

  • ndm_wt, nt_wt (int) – this tree’s weights array has shape (beams_per_batch, ndm_wt, nt_wt, nprofiles, frequency_subbands.N).

  • dm_min, dm_max (float) – DM range searched by this tree, in pc/cm^3.

  • trigger_frequency (float) – trigger frequency in MHz, for early-trigger trees.

dm_min, dm_max and trigger_frequency are display values only: they round-trip lossily through yaml (~6 significant digits), and no decode path reads them.

property dm_downsampling¶

DM downsampling factor of the coarse-grained array, relative to this tree: 2**ceil(dd_rank/2), one output DM per warp of the GPU kernel’s second dedispersion stage (whose rank is dd_rank1 in kernel code).

NOT a config field: it is fixed by the GPU kernel’s warp geometry, and ceil(dd_rank/2) varies within a primary-tree family, so no single per-primary-tree value could be right for all of its trees.

The peak-finder’s extra-DM bit count is K = log2(dm_downsampling) - frequency_subbands.pf_rank (ReferencePeakFindingKernel.xdm_rank): the width of the mu byte of an out_argmax token. It is zero unless the tree has an early trigger.

n_to_toplevel_fhi(self: pirate_frb.pirate_pybind11.DedispersionTree, n: SupportsInt | SupportsIndex) → int¶

One past the highest toplevel tree-freq channel of subband n (EXCLUSIVE), matching FrequencySubbands.n_to_fhi. Note DedispersionPlan.decode_argmax() reports an inclusive fmax, i.e. n_to_toplevel_fhi(n) - 1.

n_to_toplevel_flo(self: pirate_frb.pirate_pybind11.DedispersionTree, n: SupportsInt | SupportsIndex) → int¶

Lowest toplevel tree-freq channel of subband n (INCLUSIVE).

Channels of the 2**toplevel_tree_rank gridding, so subbands of different trees of one config are directly comparable.

property primary_tree_rank¶

Rank of this tree’s primary-tree family, toplevel_tree_rank minus one if primary_tree_index > 0 (a downsampled primary tree gives up one rank). The family’s early triggers then run from this rank down: tree_rank = primary_tree_rank - early_trigger_level.

property time_downsampling¶

Time downsampling factor of the coarse-grained array, relative to this tree. Equal to dm_downsampling, and likewise not a config field.

This value is the cdd2 registry key’s Dout (nt_out = nt_ds / time_downsampling), so pinning it to 2**ceil(dd_rank/2) is also a statement about which GPU kernels are compiled – see the Dout invariant in pirate_frb.cuda_generator.cdd2_dout().

property toplevel_tree_rank¶

The toplevel_tree_rank of the config this tree came from.

property tree_rank¶

This tree’s own rank, amb_rank + dd_rank. Equal to primary_tree_rank - early_trigger_level.
