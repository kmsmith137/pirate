DedispersionPlan¶

class pirate_frb.DedispersionPlan¶

Large, low-level data structure created from a DedispersionConfig.

This class is probably not useful for python callers! Created from a DedispersionConfig, this class contains all the derived parameters and data structures needed to execute dedispersion on the GPU. The plan includes:

  • Stage1 and Stage2 dedispersion trees

  • Kernel parameters for all processing stages

  • Memory buffer layouts and ring buffer configuration

  • Derived parameters like tree dimensions and output array shapes

The plan is immutable once constructed and is shared between dedisperser instances.

Example:

config = DedispersionConfig.from_yaml('config.yaml')
plan = DedispersionPlan(config)
print(f'Plan has {plan.ntrees} trees')
for i, tree in enumerate(plan.trees):
    print(f'Tree {i}: primary_tree_index={tree.primary_tree_index}, dm_range=[{tree.dm_min:.1f}, {tree.dm_max:.1f}]')
property beams_per_batch¶

Number of beams per batch (same as config.beams_per_batch)

property beams_per_gpu¶

Number of beams processed per GPU (same as config.beams_per_gpu)

compute_steady_state_it0(self: pirate_frb.pirate_pybind11.DedispersionPlan, itree: SupportsInt | SupportsIndex) → Array<long>¶

Returns a 1-d int64 array of shape (trees[itree].ndm_out,). A dedispersion output element (ichunk, ibeam, idm, it) of tree ‘itree’ is “steady-state”, i.e. unaffected by the zero-padding before the start of the acquisition, iff ichunk * nt_out + it >= compute_steady_state_it0(itree)[idm]. Earlier elements have artificially low out_max values (warmup artifacts, not real triggers).

property config¶

The DedispersionConfig used to create this plan

decode_argmax(self: pirate_frb.pirate_pybind11.DedispersionPlan, token: SupportsInt | SupportsIndex, itree: SupportsInt | SupportsIndex, idm_coarse: SupportsInt | SupportsIndex, itime_coarse: SupportsInt | SupportsIndex) → tuple[int, int, int, int, int]¶

Decode an out_argmax token into the winning trial parameters.

Parameters:

  • token – uint32 token from trees[itree]’s out_argmax array

  • itree – tree index, in [0, ntrees)

  • idm_coarse – dm index in out_max/out_argmax, in [0, trees[itree].ndm_out)

  • itime_coarse – time index in out_max/out_argmax, in [0, trees[itree].nt_out)

Returns:

fmin/fmax are the (inclusive) tree-freq range of the winning subband, in channels of the rank-toplevel_tree_rank gridding (0 <= fmin < fmax < 2^toplevel_tree_rank). tlo/thi are the EXCLUSIVE trailing edges at channels fmin/fmax (one past the last-summed sample), in full-resolution samples with t=0 at chunk start (tlo <= thi <= nt_in; negative values refer to earlier chunks). p is the winning peak-finding profile index. Throws on out-of-range indices or a malformed token. See DedispersionPlan.hpp for the full specification.

Return type:

Tuple (fmin, fmax, tlo, thi, p), TOPLEVEL-relative

decode_argmax2_batch(self: pirate_frb.pirate_pybind11.DedispersionPlan, itrees: Array<long>, fmins: Array<long>, fmaxs: Array<long>, tlos: Array<long>, this: Array<long>, ps: Array<long>) → tuple¶

Vectorized decode_argmax2(): converts decode_argmax_batch() outputs to physical params. Returns (freqs_lo_MHz, freqs_hi_MHz, dms, timestamps_samp, widths_samp), each a float64 array. Timestamps are CHUNK-RELATIVE toplevel sample counts (extrapolated to the full-band lowest frequency); the caller converts to absolute FPGA counts.

decode_argmax_batch(self: pirate_frb.pirate_pybind11.DedispersionPlan, tokens: Array<uint>, itrees: Array<long>, idms: Array<long>, itimes: Array<long>) → tuple¶

Vectorized decode_argmax() over 1-d nonempty arrays (one event per element; tokens: uint32, itrees/idms/itimes: int64). Returns TOPLEVEL-relative (fmins, fmaxs, tlos, this, ps), each an int64 array. Per-element validation (index ranges, malformed tokens) is inherited from decode_argmax().

property dtype¶

Data type for dedispersion (same as config.dtype)

property gpu_runnable¶

False if the plan was constructed as DedispersionPlan(config, gpu_runnable=False): per-tree Dcore values are defaults rather than cdd2 kernel-registry values, so the plan cannot be used in a GpuDedisperser. Useful in host-only contexts, such as the ‘pirate_frb show_dedisperser’ CLI.

property is_incomplete¶

True for plans built by make_incomplete_plan_from_yaml()

static make_incomplete_plan_from_yaml(config_yaml_str: str, plan_yaml_str: str) → pirate_frb.pirate_pybind11.DedispersionPlan¶

An ‘incomplete’ DedispersionPlan does not initialize any of the low-level data needed for compute kernels (especially the heavyweight MegaRingbuf) – only the members needed by decode_argmax(). This is a footgun, and is only used as a hack in FrbGrouper; it may go away in the future!

Parameters:

  • config_yaml_str – producer’s DedispersionConfig.to_yaml_string()

  • plan_yaml_str – producer’s DedispersionPlan.to_yaml_string()

property nbits¶

Number of bits per element (same as config.dtype.nbits)

property nbytes_per_segment¶

Number of bytes per GPU memory segment. Currently always constants::bytes_per_gpu_cache_line

property nelts_per_segment¶

Number of elements per GPU memory segment. Currently always constants::bytes_per_gpu_cache_line / sizeof(dtype)

property nfreq¶

Total number of frequency channels (same as config.get_total_nfreq())

property nt_in¶

Number of input time samples per chunk (same as config.time_samples_per_chunk)

property ntrees¶

Total number of stage2 trees (num_primary_trees + number of early triggers)

property num_active_batches¶

Number of active batches (same as config.num_active_batches)

property num_primary_trees¶

Number of primary trees (same as config.num_primary_trees)

property stage1_amb_rank¶

Ambient rank of each stage1 tree (= number of coarse frequency channels). Vector of length num_primary_trees.

property stage1_dd_rank¶

Active dedispersion rank of each stage1 tree. Vector of length num_primary_trees. Stage1 trees are internal to dedispersion.

to_yaml_string(self: pirate_frb.pirate_pybind11.DedispersionPlan, verbose: bool = False, zones: bool = False) → str¶

Convert plan to YAML string representation.

Parameters:

  • verbose – Include explanatory comments on fields

  • zones – Include the per-clag mega_ringbuf host/gpu zone breakdown

Returns:

YAML string representation of the plan

property trees¶

Vector of DedispersionTree objects representing stage2 output trees. Length is ntrees. Each tree corresponds to one (primary tree, early trigger) pair.
